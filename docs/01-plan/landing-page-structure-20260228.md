## 전체 스토리 흐름

```
[Hook]       히어로 — 관제실 임팩트로 시선 고정
    ↓
[Trust]      고객사 로고 바 — "이미 많은 곳이 쓴다"
    ↓
[Problem]    Pain Point — "지금 이렇게 힘드시죠?"
    ↓
[Solution]   기능 소개 — "이렇게 해결합니다"
    ↓
[Product]    제품 데모 — "직접 보여드립니다"
    ↓
[Proof]      도입 효과 — "숫자로 증명합니다"
    ↓
[Pricing]    요금제 — "이 가격에 드립니다"
    ↓
[CTA]        마지막 설득 — "지금 바로 시작하세요"
```

## 섹션별 상세 설계

### Section 1: Hero (✅ 구현 완료)

**목표:** 0.5초 안에 서비스 가치 전달 + 호기심 유발

```
레이아웃: 전체 화면 (100vh)
배경: 다크 관제실 Canvas 애니메이션
컨텐츠: 좌측 정렬 텍스트 + 우측 Canvas

요소:
- 실시간 배지 (ping 애니메이션)
- 헤드라인: "기관의 이동을 완벽하게 관리합니다"
- 서브카피: "실시간 경로 최적화부터 탑승 확인까지, 하나의 관제 화면으로."
- CTA: 무료로 시작하기 / 관제 화면 보기
- KPI 카운터 바 (하단): 운행기관 230+ / 누적탑승 12만+ / 정시율 99.2%
```

---

### Section 2: Customer Logo Bar (✅ 구현 완료)

**목표:** 사회적 증거 (Social Proof) 제공

```
레이아웃: 얇은 가로 바
컨텐츠:
- "전국 200+ 기관이 신뢰합니다"
- 기관 유형 로고/이름 스크롤 (주간보호센터, 특수학교, 어린이집 등)

개선 포인트 (향후):
- 실제 고객사 로고 추가
- 무한 스크롤 애니메이션 적용
```

---

### Section 3: Pain Point (신규 추가 권장)

**목표:** 방문자의 현재 고통을 언어화하여 공감대 형성

```
레이아웃: 3컬럼 카드
헤드라인: "지금 이런 상황이신가요?"

카드 3개:
1. 📋 "엑셀로 승객 명단 관리, 매번 수작업"
   → 해결: 엑셀 업로드 한 번으로 완성

2. 📍 "차가 어디 있는지 보호자가 매일 전화"
   → 해결: 실시간 위치 + 자동 알림

3. 🗺️ "경로 짜는 데 매일 30분 이상 소요"
   → 해결: AI가 1초 만에 최적 경로 계산

스타일: 문제(빨간 톤) → 해결(초록 톤) 전환 애니메이션
```

---

### Section 4: Features Bento Grid (✅ 구현 완료)

**목표:** 핵심 기능 6가지 시각적으로 소개

```
레이아웃: 12컬럼 Bento Grid (비대칭)
기능 목록:
1. AI 경로 최적화 (대형 카드 7col)
2. 실시간 차량 추적 (5col)
3. 승객 명단 관리 (4col)
4. 보호자 맞춤 알림 (8col)
5. 안전 점수 & 예측 정비 (6col)
6. BI 대시보드 (6col)

개선 포인트 (향후):
- 각 카드에 미니 애니메이션 추가
- 호버 시 기능 상세 팝오버
```

---

### Section 5: Product Demo (✅ 구현 완료)

**목표:** 실제 제품 UI를 보여주며 신뢰감 형성

```
레이아웃: 2컬럼 (텍스트 좌 + 모킹 우)
컨텐츠:
- 관리자 포털 대시보드 모킹
- 실시간 차량 현황 테이블
- 이번 주 정시율 애니메이션 차트

향후 추가:
- 드라이버 앱 스크린샷 섹션
- 보호자 앱 스크린샷 섹션
- 탭으로 전환하는 멀티 뷰
```

---

### Section 6: Stats / Social Proof (✅ 구현 완료)

**목표:** 숫자로 도입 효과 증명

```
레이아웃: 4컬럼 카드
지표:
- 운행 비용 20% 절감
- 관리 시간 50% 단축
- 고객 만족도 98.5%
- 셋업 5분 완료

개선 포인트:
- 실제 고객사 사례 인용 추가
- "어떻게 측정했나요?" 링크 추가
```

---

### Section 7: Testimonials (신규 추가 권장)

**목표:** 실제 사용자 후기로 마지막 신뢰 확보

```
레이아웃: 3컬럼 후기 카드 or 캐러셀
형식:
- 프로필 사진 + 기관명 + 담당자 직함
- 후기 본문 (2~3문장)
- 별점

예시 후기:
"도입 전에는 매일 아침 경로 짜는 게 가장 힘들었어요.
 Pickup 도입 후 AI가 자동으로 해줘서 오전 업무가 훨씬 여유로워졌습니다."
— 서울 ○○어린이집 원장
```

---

### Section 8: Pricing (✅ 구현 완료)

**목표:** 투명한 가격으로 신뢰 + 행동 유도

```
레이아웃: 3컬럼 (Starter / Pro★ / Enterprise)
개선 포인트:
- 연간 결제 할인 토글 추가 (월/연 전환)
- FAQ 아코디언 추가 ("해지하면 데이터는?" 등)
```

---

### Section 9: Final CTA (✅ 구현 완료)

**목표:** 결정을 미루는 방문자에게 마지막 설득

```
레이아웃: 풀 와이드 그라디언트 카드
헤드라인: "지금 바로 시작하세요"
서브: "14일 무료 체험. 신용카드 없이 시작합니다."
CTA: 무료로 시작하기 + 로그인
```
