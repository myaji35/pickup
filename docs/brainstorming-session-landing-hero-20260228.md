## Technique Sessions

### 1. Metaphor Mapping

**핵심 은유 발굴 과정:**

Pickup의 차량 관제 시스템을 직관적으로 전달할 강력한 은유를 탐색했다.

후보군: 혈관계 / 강의 지류 / 거미줄·신경망 / **항공 관제** / 별자리

**확정 은유: "도심 속 항공 관제실"**

| 항공 관제 요소 | Pickup MaaS 매핑 |
|---------------|-----------------|
| 레이더 화면 (radar sweep) | 실시간 지도 위 차량 위치 |
| 항공기 식별 태그 | 차량 번호 + 탑승 현황 |
| 비행 경로선 | 최적화된 셔틀 경로 |
| 관제탑 (control tower) | 기관 관리자 (Admin) |
| 착륙/이륙 시퀀스 | 승객 탑승/하차 순서 |
| 다수 항공기 동시 관제 | 다차량 동시 운행 모니터링 |

**확정된 3장면 시퀀스:**
```
[Scene 1] 전체 관제 뷰 (Establishing Shot)
    도시 전체를 조망 — 모든 차량이 한눈에
    "우리는 모든 것을 보고 있습니다"
         ↓
[Scene 2] 실시간 이동 중 (Action)
    개별 차량들이 각자의 경로를 따라 이동
    "지금 이 순간도 최적 경로로 운행 중"
         ↓
[Scene 3] 탑승 완료 (Resolution)
    차량 정류장 도착 → 탑승 확인 펄스(ping)
    "안전하게, 정확하게 도착"
         ↓
[Loop] 다시 전체 관제 뷰로 줌아웃
```

**시각적 톤 확정: 다크 관제실**
- 배경: 다크 네이비/블랙
- 경로선: 네온 시안/그린
- 차량: 레이더 블립 스타일 아이콘
- 이벤트: 탑승 완료 시 소나 펄스 효과

### 2. What If Scenarios

**인터랙션 아이디어 탐색:**

후보:
- 마우스 커서 → 차량 반응 ✅ 채택
- 페이지 접속 시 파워온 연출 ✅ 채택
- 스크롤 속도 → 시간 흐름 변화 (보류)
- 접속 시각 → 배경 변화 (보류)
- 라이브 실 데이터 연동 ❌ 미채택 (히어로는 연출에 집중)

**확정된 인터랙션 스펙:**
```
접속 순간:
  - 검은 화면 → 관제 그리드 라인 중앙에서 바깥으로 확산
  - 차량들이 레이더 블립처럼 하나씩 등장
  - 경로선이 그려지며 "시스템 가동" 느낌

마우스 인터랙션:
  - 커서 = 관제탑 시점
  - 커서 근처 차량이 살짝 반응 (속도 증가 or 경로 미세 변경)
  - 커서가 정류장 위 → 탑승 정보 툴팁
  - 커서 이탈 → 자동 운행 복귀
```

**핵심 UX 원칙:**
> 방문자가 무의식적으로 "내가 이 시스템을 컨트롤하고 있다"고 느끼게 만든다.

### 3. SCAMPER Method

**S — Substitute (대체)**
```
기존 패턴 → Pickup 대체
배경 이미지       → 다크 관제실 Canvas 애니메이션
정적 일러스트     → 실시간 반응형 차량 이동
스크린샷          → 인터랙티브 데모 느낌 연출
일반 SaaS 헤드라인 → B2B 신뢰 톤 카피
```

**C — Combine (결합)**
```
✅ KPI 숫자 카운터 히어로 하단 배치
   현재: 더미 숫자 카운팅 애니메이션
   향후: Rails API 실 데이터 연동
❌ 실제 UI 스크린샷 (히어로 집중 위해 미채택)
❌ 고객사 후기 오버레이 (미채택)
```

**A — Adapt (적용)**
```
레퍼런스: Uber Freight 스타일
→ 지도 기반, 심플하지만 임팩트
→ 절제된 모던함
→ 차량 이동에 집중, UI 노이즈 최소화
→ Pickup 차별화: 다차량 동시 관제, 한국 도심, B2B 기관
```

**M — Modify (수정)**
```
지도 스타일: 추상화된 격자 지도
→ 실제 지도가 아닌 도시를 암시하는 미니멀 격자
→ 항공 관제 레이더 느낌 유지
→ 한국 도심 스케일감 표현
```

**P — Put to other uses (다른 활용)**
```
히어로 애니메이션 에셋 재활용:
→ 앱스토어 프리뷰 영상
→ 영업 PT 첫 슬라이드
→ SNS 광고 소재 (15초 컷)
→ 이메일 마케팅 GIF
```

**E — Eliminate (제거)**
```
❌ 복잡한 기능 설명 텍스트
❌ 복수의 CTA 버튼
❌ 배경 소음 요소
❌ 라이브 데이터 (히어로 단계)
✅ 남기는 것: 지도 + 차량 + 헤드라인 + CTA 1개 + KPI 카운터
```

**R — Reverse (역전)**
```
일반: 방문자 → 히어로 (수동적 관람)
역전: 레이더가 방문자를 감지 → 차량이 커서 방향으로 반응
→ "관제탑이 당신을 인식했습니다" 느낌
→ 마우스 인터랙션 컨셉과 완벽 연결
```

## Idea Categorization

### Immediate Opportunities

_즉시 구현 가능한 아이디어_

1. **다크 배경 + Canvas 애니메이션 히어로** — 기술 난이도 중간, 임팩트 최고
2. **접속 시 레이더 파워온 연출** — CSS/JS 애니메이션으로 구현 가능
3. **KPI 카운터 (더미 데이터)** — 간단한 countUp.js 활용
4. **B2B 신뢰 헤드라인 카피** — 즉시 작성 가능
5. **CTA 단일화** — 무료 시작하기 버튼 하나로 집중

### Future Innovations

_개발/리서치가 필요한 아이디어_

1. **마우스 인터랙션 차량 반응** — Three.js 또는 Canvas API 구현 필요
2. **KPI 실 데이터 연동** — Rails API 엔드포인트 개발 필요
3. **3장면 루프 시퀀스** — 카메라 줌인/아웃 연출 엔지니어링 필요
4. **정류장 호버 툴팁** — 가상 데이터 설계 필요

### Moonshots

_장기적·야심찬 컨셉_

1. **실시간 라이브 관제 히어로** — 실제 운행 데이터를 익명화하여 히어로에 실시간 표시
2. **방문자 위치 기반 지도** — 방문자의 도시를 배경 지도로 자동 설정
3. **인터랙티브 데모 모드** — 히어로에서 직접 가상 경로 최적화 체험

### Insights and Learnings

1. **히어로와 실 관제의 명확한 분리**가 핵심 — 히어로는 "영화 예고편", 관제는 "실제 영화"
2. **메타포의 힘** — "항공 관제실" 하나의 은유가 디자인 방향 전체를 결정
3. **인터랙션은 설득 도구** — 방문자가 직접 조작하는 느낌이 서비스 신뢰도를 높임
4. **절제가 임팩트** — 많은 요소를 넣는 것보다 핵심 3요소(지도+차량+카피)에 집중
